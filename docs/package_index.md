This file is the quickest way to orient a reviewer to the authoritative Phase 3 materials.

This project package is mirrored on GitHub:
https://github.com/Shiwei-Jiang/multi-agents-project-constraint-aware-fitness-planner.git

## Start Here

1. Open `app/index.html` for the interactive artifact.
2. Read `docs/final_report.md` for the final design, evaluation, and reflection narrative.
3. Check `eval/evaluation_results.csv` and `eval/failure_log.md` for current-version results versus historical failures.
4. Open `docs/evaluation_evidence_view.html` for the reviewer-facing evidence overview.
5. Open `screenshots/screenshot_index.md` for the visual evidence map.
6. Open `docs/phase3_architecture_workflow.png` for the primary Phase 3 architecture and workflow diagram.
7. Open `phase_submissions/phase3/submission_packet_source.pdf` for the submission packet.

## How To Read The Evidence Package

- `eval/evaluation_results.csv` reflects the latest Phase 3 version only.
- `eval/failure_log.md` preserves historically observed failures across earlier versions, with version tags and fixes.
- Resolved failures stay visible in the current evidence package only when they were promoted into explicit regression checks.

## Evaluation Scope Note

The current package uses internal scenario-based evaluation and structured observation, not an external user study. That makes the evidence reproducible and honest, but it is still weaker than third-party observational testing for top-end evaluation claims.
