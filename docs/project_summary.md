# Project Summary

Constraint-Aware Fitness Planner is a local, runnable agentic workflow for users who want a realistic diet and workout plan without crossing into diagnosis or treatment advice. The project is agentic because the hard part is not producing text, but coordinating multiple decision stages: structuring intake, checking for missing or risky information, routing unresolved conflicts back to the human, reviewing draft plans before delivery, and demonstrating post-acceptance plan adaptation while preserving session state. The current Phase 3 artifact now delivers a more concrete reviewed plan package with a profile-fit summary, sample meal pattern, grocery focus, session blueprint, expanded weekly schedule, and next-step guidance, while keeping the coordination trace visible beside it. The final package includes the browser artifact, mirrored workflow logic for the browser and evaluation runner, saved traces, completed evaluation files, a failure log, architecture materials, screenshots, and video-support materials so a grader can inspect both the workflow and the evidence quickly.
